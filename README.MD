# Node Slot Machine

A slot machine project developed entirely in Node.js for learning and backend practice purposes.

This project was created with the goal of improving my understanding of JavaScript logic and backend concepts through a real terminal-based application.

## Concepts practiced

- Loops
- Arrays
- Objects
- Functions
- Input validation
- Game logic
- Randomization systems

## About the project

This was my second complete project focused on backend development.  
My first project was fully frontend-based, so this project became an important step in improving my logic and problem-solving skills.

The development process took around 4 days, including planning the game logic, testing different approaches, and creating sketches to organize the system structure before finalizing the application.
